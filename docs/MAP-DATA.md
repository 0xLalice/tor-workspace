# Country geometry

Made with [Natural Earth](https://www.naturalearthdata.com/).
Its vector datasets are [public domain](https://www.naturalearthdata.com/about/terms-of-use/).

Source: [1:50m Admin 0 Countries, version 5.1.1](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-countries-2/).
Pinned GeoJSON: <https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.1/geojson/ne_50m_admin_0_assets/maps/countries.geojson>

Upstream SHA-256:
`3e458fc036ad0a66411f2c1e6cac49c5d7bfb81cb1123bc513b22511a2b7fdeb`

`assets/maps/countries.geojson` keeps all 242 source features and their original geographic
coordinates (longitude, latitude, in degrees). Properties are reduced to:

- `id`: Natural Earth's `ADM0_A3` identifier, independent of ISO availability.
- `name`: English country/territory name (`NAME_EN`).
- `code`: two-letter `ISO_A2_EH`, or null when the source has no code.
- `label_point`: Natural Earth's suggested label position, not an IP location.

The ID is a GeoJSON feature member; the other fields are in `properties`.
The data uses Natural Earth's default boundaries. It is a generalized world map,
not a survey: some small territories are omitted or too small to distinguish at
the current globe size. ISO codes are retained for future route highlighting;
the map currently draws all included borders in the same style.

`assets/maps/country-map.png` is a generated 2048×1024 equirectangular texture. Red is land
coverage; green is border coverage. Its colors are data channels. The generator
preserves holes, deduplicates shared border segments, and omits artificial lines
where polygons were split at ±180° or closed along a pole.

The separate development workspace owns the optional generators below; they
are not part of the installed plugin. From that workspace, rebuild offline with
Python and `python-cairo`:

```sh
python3 tools/build_country_map.py
```

To reimport the pinned source first:

```sh
curl -fL https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.1/geojson/ne_50m_admin_0_assets/maps/countries.geojson -o /tmp/ne_50m_admin_0_assets/maps/countries.geojson
python3 tools/build_country_map.py --source /tmp/ne_50m_admin_0_assets/maps/countries.geojson
```

Import checks the source hash. The built texture is bundled; users need neither
the generator dependencies nor a network connection to render the globe.

`assets/maps/country-index.png` and `ui/theme/CountryIds.js` are generated from the same bundled polygons by `tools/build_country_map.py`. The nearest-filtered country ID texture selects route countries for border/fill highlighting; unknown codes map to zero and are not highlighted.

Ground-light atlases (`assets/images/nightwatch-lights.png`, `assets/images/firefly-lights.png`) are deterministic decorative patterns generated by `tools/build_ground_lights.py` and masked to the bundled land geometry. They are not measured city or population data. The renderer uses mipmaps to stabilize them during rotation and zoom.
